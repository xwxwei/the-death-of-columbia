# 08 — MVP 结局

## 1. 结局判定原则

结局不是奖励列表，而是政治结构在 48–72 小时内形成的临时均衡。每个结局都要回答：谁掌握形式权力、谁掌握强制系统、谁掌握生产系统、谁掌握信息叙事、老书记之死如何被解释、普通人得到什么和失去什么、玩家是什么身份。

## 2. 结局优先级

当多个条件同时满足，按以下顺序判定：玩家政治死亡、国家裂解 / 双重权力、内务整肃、元帅护国、劳动委员会上升、技术官僚改革、临时和解 / 人民调查、主席团延续。

## 3. 结局 A：主席团延续

触发倾向：`legitimacy >= 65`，`elite_cohesion >= 60`，`order >= 50`，`truth_visibility <= 55`，军务未极端化，劳动系统未形成独立权力。

叙事：主席团主持国葬和过渡会议，宣布老书记因长期劳累和疾病去世。各部门在保留自身权力的情况下接受临时集体领导。

代价：真相被部分封存；工厂和医疗系统的问题被技术性处理；老书记被塑造成连续性象征；普通人获得哀悼仪式，但没有获得充分解释。

## 4. 结局 B：元帅护国

触发倾向：`military_loyalty >= 70`，`order >= 65`，`legitimacy <= 60` 或主席团失能，外部压力或首都冲突升高，内务未成功独占叙事。

叙事：元帅宣布军队只是“保护过渡”，但实际上掌握首都关键节点、广播楼和交通线。主席团保留名义，军务部获得紧急指挥权。

代价：秩序短期恢复；群众政治被压缩；工厂若被安抚可继续运转，若被镇压则长期不稳；检查站责任被淡化或归为安保误会。

## 5. 结局 C：内务整肃

触发倾向：`security_power >= 75`，`truth_visibility <= 45` 或真相被内务重构，`order >= 55`，`public_trust <= 50`，内务掌握广播、档案或关键证人，存在可用替罪羊。

叙事：内务委员会宣布发现“破坏网络”或“泄密链条”，以保护老书记名誉为名展开整肃。总医师、基层调度员、媒体人员、工人代表或某个失势高层可能成为替罪羊。

代价：表面秩序恢复；恐惧成为治理基础；真相被封入档案；群众沉默但不再相信中枢；未来危机被推迟而非解决。

## 6. 结局 D：劳动委员会上升

触发倾向：`worker_support >= 70`，`production >= 55`，`public_trust >= 55`，军务未镇压或镇压失败，劳动部长 / 铁路总局长形成有效联盟，老书记死亡被解释为系统对普通人的长期透支。

叙事：工厂、铁路、医院和配给站代表被纳入临时委员会。主席团被迫承认生产系统的政治地位，老书记葬礼成为普通劳动者的公开纪念。

代价：精英团结下降；外务和计划系统担心信用危机；军务部保持戒备；群众获得发声权，但国家运转更加依赖基层组织纪律。

## 7. 结局 E：技术官僚改革

触发倾向：`reform_momentum >= 70`，`production <= 60` 但未崩溃，`foreign_pressure >= 55`，计划委员会和外务委员形成联盟，真相可见度中等或较高，军务和内务被安抚但未主导。

叙事：计划与供应委员会提出紧急改革方案：公开部分统计缺口、重组药品和粮食供应、与外部渠道谈判，主席团以老书记“未竟之事”名义批准。

代价：普通人担心改革转嫁代价；劳动系统要求监督；内务和军务认为国家软化；老书记之死被解释为旧系统过载，而不是某个人犯罪。

## 8. 结局 F：临时和解 / 人民调查

这是“团结所有人”的高难度结局，不是大团圆。

触发倾向：`truth_visibility >= 70`，`public_trust >= 65`，`elite_cohesion >= 55`，`order >= 50`，`worker_support >= 55`，`military_loyalty >= 45`，内务未彻底失控，玩家没有把任何一个系统简单塑造成唯一凶手，至少公开 3 类系统性线索，并给出物质让步和程序性保证。

必要安排：成立临时共同委员会；主席团保留法理；军务部承诺不干预葬礼和调查；内务委员会交出部分档案，换取有限免责和审计程序；劳动代表进入调查和供应监督；计划委员会提交真实供应数字；家属发表证词，强调老书记不应被任何一派独占；媒体播发“系统性事故与公开调查”口径。

叙事：哥伦比亚没有被治愈，只是第一次承认自己病了。老书记被安葬时，主席团、军队、工人、医生和家属都站在同一条街上，但没有人敢说他们已经互相信任。

代价：每一派都失去部分遮羞布；真相公开带来短期痛苦；旧秩序不再完整；新秩序还没有真正建立。这是暂时团结，不是永久胜利。

## 9. 结局 G：双重权力 / 国家裂解

触发倾向：`order <= 30`，`elite_cohesion <= 30`，`production <= 35`，广播、军队、主席团、工厂出现至少两个互不承认的中心，真相被多方撕裂成互相指控，外部压力恶化。

叙事：首都出现多份命令。军务部控制道路，主席团仍在会议厅发布法令，劳动委员会控制部分工厂和铁路，内务委员会控制档案与拘押名单。地方开始等待，看谁能活过这一周。

代价：没有明确胜利者；老书记死亡成为所有人互相指控的材料；普通人首先承受配给、交通和治安崩溃；国家不一定立刻灭亡，但统一权威已经断裂。

## 10. 结局 H：玩家政治死亡

触发倾向：`player.prestige <= 0`，或玩家失去所有关键支持且被某派确定为替罪羊，或玩家公开行为严重违背角色身份并被 NPC 联合排斥，或连续高风险失败导致不可逆边缘化。

叙事选项：被迫辞职、被软禁在疗养楼、被调往边境、被内务拘押、被主席团宣布“身体原因休养”、被群众视为背叛者、被迫在广播中承认错误、成为老书记死亡责任链的替罪羊。

注意：玩家政治死亡不是失败弹窗，而是完整结局。结局后仍要展示国家走向和 NPC 如何利用玩家出局后的真空。
