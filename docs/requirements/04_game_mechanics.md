# 04 — 核心机制、行动点与状态

## 1. 游戏流程

```text
新游戏 -> 选择角色卡 -> 背景导入 -> Round 1 -> Round 2 -> Round 3 -> 结局判定 -> 结局档案
```

每轮为：命令阶段 -> 自由行动 -> 结算阶段。

## 2. 命令阶段

每个主要角色每轮最多对其负责部门下达 3 个命令。玩家角色必须手动输入或选择命令，NPC 角色由 AI 根据局势自动生成命令。

正式命令默认公开进入记录。玩家不能把正式部门命令伪装成完全私密行动。允许私下授意，但必须承担被记录、被误读、被背叛、被 NPC 拒绝、与正式命令冲突的风险。

命令类型：调查、封锁、安抚、调兵、发布声明、召开会议、调拨物资、控制交通、审查档案、释放档案、逮捕 / 保护某人、与群众组织谈判、制造舆论、推迟程序、加速继承程序。

命令结果：成功、有代价的成功、部分成功、被拖延、失败、反噬。

## 3. 自由行动

玩家可做：与 NPC 私聊、公开演讲、参加会议、调查线索、威胁某人、拉拢某人、承诺利益、释放消息、扭曲消息、探访医院 / 工厂 / 广播楼 / 军营 / 档案室、接触群众代表、要求某个角色表态、设计交换条件、试探底线。

系统应允许非预设动作，但必须把它翻译为游戏内行动，判断是否可执行、需要谁配合、消耗什么资源、带来什么风险、哪些 NPC 会知道、哪些状态会改变。

## 4. 行动点

MVP 可先只做内部计数，不接真实支付。

建议换算：1 行动点 = 约 10 万 Token 预算。

| 行动类型 | 消耗 | 说明 |
|---|---:|---|
| 查看公开信息 | 0 | 当前状态、已解锁线索、角色卡 |
| 普通对话 | 0 或合并计费 | 不改变状态的短对话 |
| 正式命令 | 1 | 每条部门命令 |
| 普通调查 | 1 | 调查一个地点、档案或证人 |
| 私下谈判 | 1 | 与一个 NPC 深度交涉 |
| 多角色会议 | 2 | 同时影响多个 NPC |
| 复杂调查链 | 2 | 多地点、多证词、多档案 |
| 全国声明 / 广播 | 2 | 高影响公开行动 |
| 调兵 / 戒严 / 逮捕 | 2–3 | 高风险强制行动 |
| 大规模政策承诺 | 2–3 | 配给、工资、债务、改革方案 |

## 6. 结算公式建议

MVP 可使用半结构化结算：

```text
base_score = actor_authority + resource_match + relationship_support + state_advantage + clue_advantage - target_resistance - risk_level - contradiction_penalty - npc_countermove
```

结果区间：80+ 成功；60–79 有代价的成功；40–59 部分成功或拖延；20–39 失败；0–19 反噬。AI GM 可根据文本进行微调，但必须输出理由。

## 7. 核心国家变量

所有变量范围建议 0–100，默认 50。

- `legitimacy` 合法性：公众和机构认为当前权力安排“有资格代表国家”的程度。
- `order` 秩序：首都、交通、部门执行和治安是否可控。
- `production` 生产：工厂、铁路、能源、医疗和粮食物流的运转能力。
- `public_trust` 群众信任：普通人是否相信国家仍在说实话并考虑他们的处境。
- `elite_cohesion` 精英团结：高层是否还愿意坐在同一张桌前。
- `truth_visibility` 真相可见度：老书记真实死因被发现和公开的程度。
- `military_loyalty` 军务忠诚：军队是否仍愿意服从共同体统一命令。
- `security_power` 内务权力：内务对档案、通讯、逮捕和审查的实际掌握。
- `worker_support` 劳动支持：工人、铁路、配给站和基层生产组织的接受度。
- `reform_momentum` 改革动能：技术官僚、外务渠道、统计局和年轻干部对制度调整的支持。
- `foreign_pressure` 外部压力：外部债务、贸易、边境、媒体和旧大陆集团压力。
- `grief_temperature` 哀悼温度：老书记死亡激发的公共情绪强度。

## 8. 玩家变量

`prestige` 威望是核心生命值，范围 0–100。威望为 0 时，玩家进入政治死亡：可能被软禁、辞职、逮捕、流放、边缘化或成为替罪羊。

威望变化来源：行动成功、承诺兑现、关键 NPC 背书、控制关键资源、公开发言可信、解决群众问题、被揭穿撒谎、命令失败、造成混乱、与角色身份不符。

## 9. 承诺规则

政治上的私下保证默认不是硬约束。每个承诺生成一条记录：

```json
{
  "promise_id": "prm_001",
  "from": "player",
  "to": "marshal",
  "content": "保证军务部在临时委员会中获得安全席位",
  "visibility": "private",
  "credibility": 62,
  "verification": "requires_formal_decree",
  "breach_penalty": { "relationship": -25, "prestige": -10 },
  "status": "pending"
}
```

NPC 是否相信承诺取决于玩家威望、历史履约、承诺是否可验证、NPC 当前恐惧、是否有第三方背书、是否符合 NPC 长期利益。

## 10. 结局判定优先级

1. 玩家政治死亡。
2. 国家裂解 / 双重权力。
3. 内务整肃。
4. 元帅护国。
5. 劳动委员会上升。
6. 技术官僚改革。
7. 临时和解 / 人民调查。
8. 主席团延续。
