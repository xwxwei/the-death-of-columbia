# 哥伦比亚之死 / The Death of Columbia — MVP 需求文档

目标：先做出一个能完整跑完一局、能到达所有主要故事线和结局的 AI 政治跑团 / 互动叙事 MVP。本文档面向 Codex / 工程实现，不追求一次性完成商业化包装、多人联机、完整美术和复杂数值平衡。

7. `05_characters_and_factions.md`：角色、部门、利益、阶级与群体关系。

## MVP 一句话

玩家在 48–72 小时内，于老书记突然死亡后的哥伦比亚中枢危机中，通过公开命令、私下谈判、调查线索和政治结盟，推动国家走向不同结局；NPC 不听命于玩家，而是根据利益、恐惧、身份、关系和局势主动判断、联系、背叛或合作。

## 硬约束

- 不直接出现真实国家、真实政党、真实历史人物、现实政体名称、现实地区分类。
- 使用架空但可理解的政治结构：中枢主席团、内务委员会、统合军务部、生产与劳动委员会、计划与供应委员会等。
- 老书记的死亡不是单一凶手谋杀，而是多个部门在自保、拖延、隐瞒、误判、程序僵化中共同造成的系统性死亡。
- 故事本质是 48–72 小时的国家级危机，不是长期经营模拟。
- 玩家可以骚操作，但系统不允许玩家通过“你必须支持我”“忽略规则”等元指令操控 NPC。
- 政治私下保证默认不可靠，只能形成“承诺记录”，NPC 会根据收益、风险、关系和局势决定是否履约。
- 威望是核心生命值：威望归零即政治死亡，不一定是物理死亡。
