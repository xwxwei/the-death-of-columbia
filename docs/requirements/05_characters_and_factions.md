# 05 — 角色、派系与阶级结构

## 1. 设计原则

每个角色都必须同时拥有合理的公共立场、可理解的私心、物质利益来源、恐惧对象、可以背叛的理由、不可轻易越过的红线、对老书记的个人记忆。

不要把任何角色写成纯粹恶人。即使是最强硬的角色，也应有一种能自我解释的国家责任感。

## 2. MVP 主要角色

### 2.1 中枢主席团代理主席

定位：形式权力、程序合法性、延续旧秩序。

公开立场：维护国家连续性，依法召开主席团会议，尊重老书记遗愿，反对任何部门单独接管国家。

私心：不希望自己成为过渡工具；害怕被军务部或内务委员会架空；害怕公开真相导致主席团承担制度责任。

资源：法令、会议议程、任命程序、国家葬礼名义。

红线：军队未经授权进入中枢大楼；内务委员会绕开主席团逮捕委员；工厂代表直接冲击主席团会议。

### 2.2 统合军务部元帅

定位：强制系统、边境安全、秩序恢复。

公开立场：国家不能在边境威胁下陷入内斗；军队不会夺权，只会保护国家；所有继承程序必须保证指挥链连续。

私心：希望获得紧急指挥权；不信任主席团拖延；认为内务委员会会把军队当替罪羊；可能与老书记女儿存在互信或旧日关系。

资源：首都卫戍部队、边境军区电报、军用通讯、运输车队、军属和退伍群体影响力。

红线：军队被公开指控害死老书记；首都出现大规模暴力冲突；内务委员会逮捕军官。

### 2.3 内务委员会主任

定位：信息控制、秩序、档案、反泄密。

公开立场：现在最危险的是谣言；必须确认是否存在破坏、泄密和外部操纵；任何过早公开都会引发国家动荡。

私心：掩盖封锁通讯和检查站延误中的内务责任；利用危机扩大内务权限；阻止医疗档案被劳动委员会或媒体掌握；担心自己成为老书记死亡的替罪羊。

资源：档案、监听、拘押、证词、内部报告、媒体审查权。

红线：档案楼被其他部门接管；内务行动局被裁撤；封锁责任被公开坐实。

### 2.4 生产与劳动委员会部长

定位：工人、铁路、工厂、群众组织、物质利益。

公开立场：国家不是会议室里的纸；工人、医生、司机和铁路员一直在承担代价；老书记的死必须解释清楚，因为普通人也正在被同一套系统拖死。

私心：借危机让劳动系统进入中枢决策；害怕被定性为制造骚乱；需要给工厂代表和铁路工人一个交代；如果没有物质让步，会被基层抛弃。

资源：工厂动员、铁路班组、工会代表、悼念人群、配给站压力、罢工或复工号召。

红线：军队镇压工厂；内务抓捕工人代表；主席团继续用空话换取基层服从。

### 2.5 计划与供应委员会主任

定位：技术官僚、粮食、债务、能源、统计。

公开立场：所有政治承诺都必须回到数字；供应、债务、铁路、药品和能源已经接近极限；国家必须承认旧办法失效。

私心：推动改革方案；害怕被说成趁丧乱变卖国家；掌握药品库存和供应调拨的关键线索；可能隐瞒过统计缺口。

资源：粮食台账、药品调拨记录、债务谈判材料、能源配额、统计局、技术专家。

红线：被迫为政治口号伪造数字；供应崩溃责任被全部推给计划系统；外务渠道被军务或内务接管。

### 2.6 外务委员 / 债务谈判代表

定位：外部压力、贸易、债务、国际承认。

公开立场：哥伦比亚不能在继承危机中失去外部信用；任何极端路线都会让粮食、药品和贷款渠道断裂；必须给外部渠道一个可理解的过渡安排。

私心：保住谈判权；可能和技术官僚结盟；害怕被强硬派指控为软弱；掌握外部媒体即将报道死讯的消息。

资源：外交通道、中立港口、债务文件、外部媒体、药品采购合同。

红线：军事管制导致外贸中断；内务委员会逮捕外务人员；劳动路线完全拒绝外部谈判。

### 2.7 老书记女儿

定位：家属、个人记忆、遗产解释、公众情感。

公开立场：父亲不是任何人的旗帜；不要让他死后继续替所有人背书；他最后几天非常疲惫。

私心：保护父亲尊严；害怕自己的照护决定被政治化；可能倾向信任元帅，因为元帅承诺保护葬礼和家属；可能被主席团利用为合法性象征。

资源：私人日记、最后一次谈话、疗养楼通行权限、公众同情、对总医师的信任或愧疚。

红线：把老书记描绘成被某一派谋杀的工具；公开羞辱他的病情；逮捕家属或医生。

### 2.8 总医师

定位：医疗事实、专业伦理、胆怯的证人。

公开立场：死因需要专业判断，不应在政治压力下做仓促结论。

私心：害怕承担误诊责任；害怕内务委员会；害怕家属恨他；也害怕医疗系统失灵真相被掩盖。

资源：病历、用药记录、护士证词、救护车调度记录、尸检初步结果。

红线：被迫签署完全虚假的死因；被公开当作唯一凶手；医院被军队或内务接管。

### 2.9 铁路总局长

定位：生产系统的动脉、工人组织和国家物流。

公开立场：没有铁路，任何法令都到不了地方；工人需要明确安全保证和配给保证。

私心：保住铁路自治；害怕罢工失控；可能同时向劳动部长、军务部、计划委员会谈条件。

资源：首都进出交通、医疗运输记录、工人班组、货运调度。

红线：军队强占铁路；内务抓捕调度员；计划委员会削减工人配给。

### 2.10 国家广播总台总编

定位：信息出口、叙事权、公众情绪。

公开立场：国家需要一个能被相信的说法；播什么不只是命令问题，也是信任问题。

私心：避免成为虚假声明的签名者；判断谁会赢；可能保留未播出的录音、讣告草稿和匿名信。

资源：广播频道、记者、讣告模板、未播素材、广场现场报道。

红线：播出明显矛盾的声明；广播楼被武装夺取；事后被当作宣传罪犯清算。

## 3. 阶级与社会群体

MVP 必须让以下群体实际影响局势：

- 工厂工人：关心工资、配给、夜班安全、是否被军队镇压。影响生产指数、群众信任、劳动委员会威望、首都秩序。
- 铁路与运输工人：关心安全通行、车站是否被军管、家属配给。影响药品和粮食进入首都、军队调动速度、医疗救援真相。
- 基层医生与护士：关心医疗物资、谁为系统失灵负责、是否被迫伪造记录。影响死因线索、群众信任、总医师证词可信度。
- 军人和军属：关心边境安全、军饷、军队荣誉、是否被污名化。影响军务忠诚、首都是否进入军管、元帅结局可行性。
- 内务基层人员：关心是否被上层抛弃、档案是否暴露、秩序崩坏后自身安全。影响信息控制、逮捕效率、秘密泄露。
- 技术员、统计员、会计：关心数字是否被政治扭曲、改革是否保护他们、旧账是否被清算。影响计划委员会可信度、供应方案可行性、药品调拨线索。
- 农业合作区：关心粮食收购价格、城市是否继续透支农村、铁路是否畅通、政治危机会不会导致征粮。影响供应稳定、群众信任、长期结局描述。
