# 03 — 故事结构

## 1. 总体时长

游戏发生在 48–72 小时内。这不是一场长期政治模拟，而是一场国家权力结构的相变过程：老书记死亡前所有系统勉强同步；老书记死亡后，各系统开始独立计算自己的安全；第三天前后，某种临时秩序必须出现，否则国家进入双重权力或裂解。

## 2. 三轮结构

每轮固定三阶段：命令阶段、自由行动、结算阶段。每轮都必须推进权力归属、老书记死因、群众反应、NPC 结盟、国家状态变化。

## 3. 第一轮：和平轮 / 秩序尚存

时间：第 1 天上午至下午。

表面局势：老书记没有出席例行晨会。官方口径是“休息”。各部门仍然按旧流程运转，但都在确认一件事：老书记到底还能不能签字？

必出事件：

- 老书记缺席晨会。
- 中枢主席团要求确认健康状况。
- 统合军务部要求边境预算签署。
- 内务委员会建议封锁疗养楼通讯。
- 生产与劳动委员会收到首都工厂停工威胁。
- 计划与供应委员会发现药品、粮食或燃料统计不一致。
- 老书记女儿要求“不要让他再被会议折磨”。
- 总医师含糊表示“情况复杂”。

玩家任务：在信息不足时选择优先级：稳住中枢会议、调查医疗情况、处理工厂和铁路、联络军务部、控制媒体、和家属建立信任、准备继承程序。

第一轮结算重点：哪些部门知道老书记已经危险；哪些 NPC 开始私聊；是否有谣言流出；工厂和铁路是否被安抚；军务部是否进入戒备；内务是否扩大封锁；玩家威望首次上升或下降。

## 4. 第二轮：裂缝轮 / 死讯确认

时间：第 1 天夜间至第 2 天下午。

表面局势：老书记死亡事实已无法继续掩盖，但死讯是否立即公布、如何公布、谁来主持哀悼和继承，仍然未定。

派系叙事：主席团希望说是自然死亡并立即进入合法继承；军务部希望强调边境威胁和紧急状态；内务委员会希望强调破坏、泄密和秩序风险；劳动委员会希望追问为什么医院、工厂和配给都在失灵；计划委员会希望把死亡解释为旧制度过载；家属希望保留老书记尊严。

必出事件：

- 死讯确认或泄露。
- 医疗记录出现矛盾。
- 治安检查站延误救护车的事实浮出。
- 药品库存和签收记录对不上。
- 国家广播总台要求统一口径。
- 工厂代表要求参加哀悼委员会。
- 军务部要求临时指挥权。
- 内务委员会开始搜查泄密源。
- 首都出现自发悼念人群。

玩家任务：公开真相、部分公开还是封锁；支持哪种临时权力安排；是否牺牲某个部门作为替罪羊；是否允许群众组织参加葬礼和调查；是否与某派签订秘密保证；是否让军队进入首都关键点位；是否打开档案。

第二轮结算重点：真相可见度、群众信任、精英团结度、军队忠诚、内务扩权、工厂与铁路运转、玩家是否可靠、NPC 是否形成反玩家联盟。

## 5. 第三轮：摊牌轮 / 权力归属

时间：第 2 天夜间至第 3 天。

表面局势：葬礼、紧急会议、广播、军队调动、工厂停工、档案泄露几乎同时发生。国家必须回答三个问题：谁代表老书记之后的合法性？老书记到底为什么死？普通人接下来要付出什么代价？

必出事件：

- 国家葬礼或临时哀悼集会。
- 中枢主席团紧急会议。
- 统合军务部或首都卫戍部队的最后通牒。
- 内务委员会要求抓捕泄密者或“破坏分子”。
- 劳动委员会要求公开调查与物质让步。
- 计划委员会提出紧急供应 / 债务 / 改革方案。
- 媒体总编选择播发哪份声明。
- 老书记女儿发表或拒绝发表私人证词。
- 玩家威望进行最终判定。

第三轮结算重点：谁控制广播、谁控制首都关键道路、谁控制主席团会议、谁控制工厂和铁路、谁能给出被公众接受的死因解释、谁被当作旧秩序的继承者 / 改革者 / 叛徒 / 替罪羊。

## 6. 单局节奏

快速模式：每轮只展示 3–5 个关键选择，NPC 私聊以摘要形式出现，适合 20–40 分钟体验。

深度模式：玩家可多次自由输入，可调查更多线索，NPC 行动更复杂，适合 1–3 小时体验。

MVP 可先实现深度模式的结构，但 UI 上提供“继续结算”按钮，让不想深聊的玩家也能推进。
