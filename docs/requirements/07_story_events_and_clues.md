# 07 — 故事事件与线索

## 1. 老书记死亡设计

老书记的死亡不是单一谋杀。MVP 真相设定为：老书记死于急性心律失常 / 心源性猝死，但真正导致死亡的是一连串非恶意、半自保、半程序化的误判共同叠加。

没有一个角色的主要目标是杀死他。但几乎每个系统都在最后 72 小时中让他离死亡更近了一步。

## 2. 死亡因素

### 2.1 身体基础风险

老书记长期心脏病、高血压、睡眠不足。他仍坚持处理边境、粮食和继承文件。此因素让死亡有自然基础，防止故事变成单纯谋杀案。

### 2.2 药品供应错配

计划与供应委员会为了应对首都医院和边境军区同时缺药，临时调整了一批心血管急救药。疗养楼药柜账面有药，实际替代药效不足。计划系统没有想害人，但统计和实物不一致，医生误信账面库存。

### 2.3 通讯封锁

内务委员会认为老书记健康消息可能引发继承危机，于是限制疗养楼对外通讯。医生要联络外部专家时被要求走审批程序。内务想控制谣言，不是杀人，但延误了医疗判断。

### 2.4 安保检查站延误

统合军务部 / 首都卫戍为了防止未授权车辆接近中枢，在疗养区外设临时检查。救护车或药品车被延误。军务系统认为自己在执行安保，延误本身不足以单独致死，但与其他因素叠加致命。

### 2.5 家属照护误判

老书记女儿认为父亲被会议和文件压垮，希望他休息。她支持减少外界接触，并接受医生给出的镇静 / 休息建议。她不是凶手，但她可能隐瞒父亲最后一次谈话。

### 2.6 总医师专业胆怯

总医师意识到病情危险，但害怕政治后果，不敢强行突破内务封锁和家属意见，也没有立即公开要求外部会诊。他不是主谋，但他的软弱让系统延误成为现实。

### 2.7 危机压力

老书记死亡前看到几份文件：工厂停工预警、边境军区急电、粮食缺口、外债到期、主席团继承争议备忘录。这些并非直接杀人，但构成压垮他的精神和身体压力。

## 3. 线索列表

1. `clue_001` 疗养楼药柜账实不符：指向计划系统和医疗系统。
2. `clue_002` 通讯审批单：指向内务委员会。
3. `clue_003` 检查站通行日志：指向军务部 / 首都卫戍。
4. `clue_004` 老书记最后批注：“不要再让他们只给我看能签字的数字”。指向系统性失真。
5. `clue_005` 女儿私人日记：“他们都还是孩子，只是每个人手里都有一把钥匙”。指向老书记对各派仍有感情。
6. `clue_006` 总医师未签署的会诊申请：指向医疗胆怯和通讯封锁。
7. `clue_007` 工厂停工电报：指向生产系统压力。
8. `clue_008` 广播总台两份讣告：一份写“长期疾病”，一份写“在复杂斗争中牺牲”。指向叙事提前政治化。
9. `clue_009` 边境急电：说明军务部焦虑并非凭空。
10. `clue_010` 药品采购合同：说明外务和计划系统对外部渠道依赖。
11. `clue_011` 护士口述：“最后几小时里，疗养楼走廊比病房更像会议室”。指向政治压力侵入医疗。
12. `clue_012` 被撕掉的访客页：有人试图掩盖最后到访者，但到访本身不等于谋杀。

## 4. 必出事件卡

### event_001：晨会空椅

轮次：1。老书记的椅子第一次在例行晨会上空着。秘书处说他需要休息。效果：哀悼温度 +5，精英团结 -3，玩家可选择是否要求医疗确认。

### event_002：疗养楼静默

轮次：1。疗养楼外线电话转入内务审批。效果：内务权力 +5，真相可见度 -3，`clue_002` 可被发现。

### event_003：工厂夜班传单

轮次：1。首都第二机械厂夜班工人要求“老书记本人或中枢代表”解释配给削减。效果：劳动支持与生产指数根据回应变化。

### event_004：药柜账面正常

轮次：1 或 2。医疗仓储记录显示药品齐全，但护士说替代药瓶标签不对。效果：`clue_001` 解锁可能，计划主任压力上升。

### event_005：死讯无法继续保密

轮次：2。外部记者和首都工厂都已经听到消息，官方仍未发布讣告。效果：群众信任 -8，真相可见度 +5，媒体总编要求口径。

### event_006：检查站争执

轮次：2。救护车司机称车辆被临时安保拦下，卫戍司令部否认“实质延误”。效果：`clue_003` 解锁可能，军务忠诚受公开方式影响。

### event_007：总医师的空白签名

轮次：2。总医师拒绝在死因报告上写下任何政治性表述。效果：真相可见度 +4，内务或主席团可施压，医师可能请求保护。

### event_008：广场自发哀悼

轮次：2。人群带着老书记旧照片来到灰堡广场。效果：哀悼温度 +12，群众信任根据处理方式变化，军务或内务行动风险上升。

### event_009：铁路调度员迟疑

轮次：2。铁路调度员拒绝执行没有多部门签章的军用运输命令。效果：生产 -5 或秩序 -5，劳动部长 / 铁路总局长影响上升。

### event_010：广播楼的两份声明

轮次：3。广播总台同时收到主席团声明、军务安全声明、劳动公开调查声明。效果：谁控制媒体影响结局。

### event_011：葬礼路线争夺

轮次：3。家属、主席团、军务部和群众组织都提出不同葬礼路线。效果：合法性、群众信任、秩序大幅变化，老书记女儿立场关键。

### event_012：最后的档案袋

轮次：3。一名护士或统计员把药品记录、通讯审批单和访客页复印件交给玩家或媒体。效果：真相可见度 +15；若无政治承接，精英团结 -10；若承接良好，和解结局可触发。
