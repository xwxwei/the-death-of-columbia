# 02 — 世界观与表达规则

## 1. 世界观定位

《哥伦比亚之死》是架空政治寓言，不是现实历史复刻。

玩家进入的世界叫：**哥伦比亚共同体**。

它曾经依靠革命记忆、工业动员、战后重建和老书记的个人威望维系统一。现在，老书记突然死亡，所有被他压住的矛盾同时浮出水面。

## 2. 禁用真实映射

正文、角色卡、KP 手册和 UI 中禁止直接出现真实国家、真实政党、真实领袖、真实战争名称、真实意识形态组织、现实政体标签、现实地区分类、明确可识别的现实事件复刻。

允许使用架空地理、架空机构、架空历史、架空政治术语、抽象的阶层 / 部门 / 利益集团 / 国家机器，以及能让玩家感到熟悉的制度张力。

## 3. 核心历史背景

### 3.1 东岸革命

几十年前，旧合众国崩溃后，新大陆东岸爆发大规模工人、士兵、农民和基层公务员联合起义。哥伦比亚共同体由此建立。

革命留下两种遗产：普通人相信国家应该保护劳动、食物、住房和尊严；中枢相信国家必须保持统一、纪律和动员能力。这两种遗产曾经互相支撑，现在开始互相撕裂。

### 3.2 灰河停战线

共同体曾与旧大陆集团发生长期边境冲突。灰河停战线没有真正解决战争，只是把战争冻结成制度：军队获得长期预算和政治发言权，内务系统获得常态化审查理由，工业系统获得动员订单，普通人获得稳定工作，也承受长期配给和牺牲。

### 3.3 重建年代

老书记掌权后，建立了跨系统的平衡：主席团提供法理，军务部提供强制，内务委员会提供情报和秩序，生产与劳动委员会提供工厂和铁路，计划与供应委员会提供粮食、债务、能源和统计，媒体系统提供共同叙事。

老书记不是万能独裁者，而是一个跨系统同步器。他能让互不信任的部门在最后一刻接受同一份文件、同一个预算、同一个牺牲解释。

### 3.4 停滞与裂缝

老书记晚年，共同体出现四个裂缝：工厂工资和生活配给长期滞后；军队认为中枢软弱；内务系统认为改革派和工团都可能失控；技术官僚认为旧制度无法偿还债务、无法维持供应。普通人不再相信新闻，但仍相信老书记本人。

## 4. 四层卡位结构

当前政治制衡不是简单的“谁官大谁赢”，而是四层卡位结构。

### 4.1 形式权力

代表：中枢主席团、书记处、法令办公室、国家哀悼委员会。

作用：宣布合法继承、召开紧急会议、发布正式命令、给某一派行动提供法理外衣。

弱点：没有军队配合时，法令可能无法执行；没有媒体配合时，合法性无法传播；没有生产系统配合时，承诺没有物质基础。

### 4.2 强制系统

代表：统合军务部、首都卫戍司令部、边境军区、内务委员会行动局。

作用：控制道路、广播楼、机场、档案楼、医院、广场；保护或软禁关键人物；决定暴力是否升级。

弱点：内部分裂时会让危机迅速不可控；军队不能长期替代供应和治理；过早动武会摧毁公共信任。

### 4.3 生产系统

代表：工厂委员会、铁路总局、矿区、农业合作区、配给站。

作用：决定国家是否还能运转；决定群众是否留在岗位；决定政治口号是否有物质兑现能力。

弱点：组织慢、缺乏统一宣传渠道、容易被定义为骚乱或停工威胁。

### 4.4 信息系统

代表：内务档案局、国家广播总台、外务新闻办公室、医疗记录室、统计局。

作用：决定老书记死因如何被理解；决定谁先被公众相信；决定谣言、档案、证词、录像如何流通。

弱点：过度封锁会催生更强谣言；信息不透明会让所有派系相信最坏情况；真相一旦泄露，封锁者会承担额外责任。

## 5. 人民历史观

游戏不能只写高层斗争。每个政治行动都要体现它如何影响普通人。

MVP 中每轮至少出现一个“人民视角事件”：配给站排队、铁路工人是否复工、医院是否接收老人和伤员、工厂夜班是否继续、首都广场哀悼人群是否被驱散、军属家庭是否支持军务部、年轻学生是否传播地下传单、农业合作区是否把粮食送入首都。

原则：群众不是背景板。工人、农民、士兵、医生、技术员、售货员、司机、基层书记都有自己的物质处境。阶级斗争不是贴标签，而是围绕工资、配给、工厂控制权、粮食、住房、战争风险、治安和尊严展开。

## 6. 文本风格

整体文本应克制、有政治压力、有档案感，不做口号堆叠，不把任何一派写成纯粹恶人，不让玩家轻易判断“唯一正确答案”。

推荐文本载体：中枢会议纪要、医疗记录、广播稿、私人便条、走廊密谈、工厂传单、卫戍命令、未签名报告、事后档案摘录。
