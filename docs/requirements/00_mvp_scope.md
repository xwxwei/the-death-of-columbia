# 00 — MVP 范围

## 1. MVP 目标

第一版只解决一个问题：让玩家可以从开局进入三轮危机流程，完成命令、自由行动、调查、NPC 互动、阶段结算，并进入所有主要结局之一。

MVP 不要求美术完整，不要求多人，不要求复杂动画，不要求真实支付接入，不要求所有文本最终润色。

## 2. MVP 必须包含

### 2.1 开局

- 显示游戏标题：`哥伦比亚之死 / The Death of Columbia`
- 显示短背景说明。
- 玩家选择一个角色卡。
- 系统创建玩家状态、NPC 状态、国家状态、隐藏线索状态、关系矩阵、初始事件队列。

### 2.2 角色卡

MVP 至少支持 6 个可选 / 可模拟角色：

1. 中枢主席团代理主席。
2. 统合军务部元帅。
3. 内务委员会主任。
4. 生产与劳动委员会部长。
5. 计划与供应委员会主任。
6. 外务委员 / 债务谈判代表。

老书记女儿、总医师、铁路总局长、首都工厂代表、媒体总编作为关键 NPC。

### 2.3 三轮结构

一局游戏固定三轮，每轮三阶段：

1. 命令阶段：每个主要角色对其负责部门下达最多 3 个命令。
2. 自由行动：公开发言、私聊、调查、谈判、威胁、交易、造势。
3. 结算阶段：GM 结算命令、NPC 自主行动、状态变化、事件触发。

三轮对应 48–72 小时：

- 第一轮：和平轮 / 秩序尚存。
- 第二轮：裂缝轮 / 死讯确认、责任争夺。
- 第三轮：摊牌轮 / 权力归属、真相处理、群众反应。

### 2.4 AI GM

AI GM 必须负责：解释局势、判断玩家行动是否合法、执行状态更新、生成阶段总结、控制隐藏线索揭示、调用 NPC 决策、判断结局。

AI GM 不能：因玩家要求而修改规则；让所有 NPC 自动支持玩家；把现实国家或真实历史人物直接带入正文；让玩家随意回滚关键行动。

### 2.5 NPC 自主决策

每个 NPC 必须有目标、恐惧、红线、当前情报、对其他角色的信任度、对玩家的信任度、对局势的判断、是否愿意联系其他 NPC 的规则。

NPC 不只是回答玩家，还会主动私聊其他 NPC、建立临时同盟、传播或封锁消息、承诺、拖延、欺骗、背叛，并依据自身利益判断是否执行玩家建议。

### 2.6 死因线索

老书记死亡必须是多因素共同导致：身体基础风险、药物或医疗流程问题、通讯封锁、安保延误、部门隐瞒、家属误判、危机压力。没有一个角色以“杀死老书记”为主要目的。

玩家可以调查并拼出“系统性死亡”的真相，也可以把真相政治化、隐瞒、嫁祸或公开。

### 2.7 结局

MVP 至少包含 8 个结局：主席团延续、元帅护国、内务整肃、劳动委员会上升、技术官僚改革、临时和解 / 人民调查、双重权力 / 国家裂解、玩家政治死亡。

每个结局都要能由状态变量触发，不是随机给出。

### 2.8 结局后档案

结局后显示玩家行动摘要、关键状态变量、各 NPC 最终立场、部分私聊 / 密信 / 决策理由回放、老书记死亡真相揭示程度、玩家评价。

## 3. MVP 暂不做

多人联机、语音对话、Steam 成就、iOS 内购正式接入、复杂地图、大规模经济模拟、自定义剧本编辑器、图像生成、长期存档云同步、真实政治事件库、版权音乐采样。

## 4. MVP 完成定义

- 新建游戏后可以无人工干预跑完三轮。
- 任意一个玩家角色都能跑通。
- AI NPC 不会明显出戏。
- 所有 8 个结局都可通过测试状态触发。
- 玩家威望归零时能进入政治死亡或被边缘化分支。
- 结局后能看到至少 5 条秘密行动 / NPC 决策记录。
- 至少 12 个关键事件卡能在流程中触发。
- 至少 12 个线索能影响死因解释和结局正当性。
